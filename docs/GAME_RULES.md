# Правила FlappyBird 2.0

Касание поля даёт импульс вверх. Птица должна пройти между верхней и нижней трубой. Одна полностью пройденная пара труб даёт одно очко. Столкновение с трубой, землёй или верхней границей завершает попытку.

Игровой мир: 360 × 640, земля на Y = 590; птица в X = 100, радиус = 12; ширина трубы = 62. Гравитация = 950, импульс взмаха = −315. Фиксированный шаг симуляции = 1/120 секунды. Длинные задержки кадра ограничиваются 0,1 секунды, чтобы не переносить птицу через препятствия одним скачком.

| Сложность | Скорость | Проход |
|---|---:|---:|
| Easy / Лёгкий | 110 | 200 |
| Normal / Обычный | 130 | 166 |
| Hard / Сложный | 155 | 144 |

Изменение уровня влияет только на следующий полёт. Генератор ограничивает центр прохода диапазоном 175–410 и изменение между соседними трубами величиной 70. Таблицы рекордов разделены по сложности. При равном счёте выше более ранний результат, затем используется идентификатор для стабильного порядка.

Пауза останавливает симуляцию и таймер страницы. Продолжение — после трёх секунд отсчёта. Сворачивание ставит игру на паузу и отменяет отсчёт. Кнопка «Завершить и сохранить попытку» на паузе завершает полёт с текущим счётом. До первого взмаха выход не создаёт запись.

Результат содержит время активной симуляции, прежний рекорд выбранного уровня, текущий лучший счёт и прогресс медали. Бронза: 10, серебро: 25, золото: 50, платина: 100. Выше 100 показывается завершение коллекции медалей.

Достижения общие: 1, 10 и 25 очков за один полёт, 100 завершённых сохранённых попыток. Они фиксируются в SQLite в одной транзакции с результатом. Повтор записи того же GUID не создаёт дополнительную попытку и не меняет даты достижений.

Старые результаты версии 1 сохраняются на Normal. Достижения за них начисляются при обновлении. Рекорды хранятся на устройстве; установка приложения заново с удалением данных очищает локальную историю.
