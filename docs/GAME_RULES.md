# Правила версии 1

- Только Android, портретная ориентация, один классический режим, локальная таблица.
- Касание игрового поля запускает попытку и придаёт птице скорость вверх. Удержание не даёт повторных взмахов.
- Виртуальное поле: 360 × 640, земля на Y=590. Поле вписывается с сохранением пропорций, свободные поля заполняются фоном.
- Физика обновляется фиксированным шагом 1/120 секунды. Скорость труб 130 единиц/с, гравитация 950 единиц/с², взмах −315 единиц/с.
- Радиус столкновения птицы 12; изображение немного крупнее. Круг проверяется против прямоугольников труб, земли и верхней границы.
- Трубы шириной 62, проход 166, расстояние между левыми краями 220. Центр первого прохода Y=280, следующие смещаются не более чем на 70 и ограничены диапазоном 175…410.
- +1 очко, когда правая граница пары труб полностью проходит левую границу области столкновения птицы. Каждая пара засчитывается однократно. Столкновение имеет приоритет перед начислением очка в том же шаге.
- Столкновение завершает попытку. Нулевой результат тоже сохраняется. Выход в меню во время незавершённой попытки позволяет начать новую без записи старой.
- Пауза и сворачивание замораживают мир. Возвращение из фона не возобновляет полёт автоматически. Продолжение — через 3–2–1.
- У результата один GUID на всю попытку. Повтор записи с этим GUID не создаёт вторую строку.
- При ошибке сохранения доступны повтор и явный отказ. Новую попытку до разрешения ошибки начать нельзя.
- Рейтинг: очки по убыванию, время UTC по возрастанию; при полном совпадении GUID задаёт стабильный порядок. Даты отображаются по местному времени устройства.
- Имя: до 20 символов, пустое имя заменяется на «Игрок». Для попытки сохраняется имя на момент завершения.
- Медали: бронза от 10, серебро от 25, золото от 50, платина от 100. Показана старшая медаль текущей попытки.
