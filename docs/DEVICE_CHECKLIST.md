# Проверка на Android

Проверять отдельно Debug и Release. Для разных размеров использовать минимум телефон и второй эмулятор/телефон; увеличенный системный шрифт проверять отдельно.

- Первый запуск: меню открывается, SQLite создаётся автоматически, рекорд равен нулю.
- Касание поля запускает полёт; взмах срабатывает при нажатии, удержание не повторяет взмахи.
- За пройденную пару труб даётся ровно одно очко. Столкновение завершает попытку.
- После завершения: счёт, рекорд, медаль/порог, быстрый перезапуск. Одна попытка — одна запись.
- Рекорды: пустая таблица, несколько попыток, одинаковые очки, больше 10 попыток.
- Пауза: мир неподвижен, продолжение после обратного отсчёта. Свернуть приложение также во время отсчёта: игра должна остаться на паузе.
- Завершить приложение через список приложений/force-stop и открыть снова: рекорды и настройки остаются.
- Изменить имя, выключить звук и вибрацию, сохранить, перезапустить и проверить.
- На компактном экране доступны все кнопки: меню и диалоги прокручиваются; поле сохраняет пропорции. Проверить вырез камеры и системные панели.
- При нехватке места/ошибке SQLite: понятный статус, повторное сохранение с тем же идентификатором, явный отказ без зависания.
- Включить авиарежим: новая игра, рекорды и настройки работают.
- Проверить Release на физическом устройстве: создание базы, сохранение, перезапуск. Проверка только Debug недостаточна.

Не считать пункт пройденным без фактического выполнения. Автоматические проверки SQLite на ПК дополняют, но не заменяют проверку телефона.
